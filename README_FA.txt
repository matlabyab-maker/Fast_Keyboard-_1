Fast Keyboard - نسخه 16

این نسخه بخش Input Method را برای استفاده واقعی از کیبورد تکمیل می‌کند.

مراحل روی گوشی:
1) برنامه را نصب کنید.
2) وارد برنامه شوید و «فعال‌سازی Fast Keyboard» را بزنید.
3) در فهرست کیبوردها Fast Keyboard را روشن کنید.
4) «انتخاب Fast Keyboard» را بزنید و Fast Keyboard را انتخاب کنید.
5) برای تست، در کادر متن برنامه لمس کنید یا «نمایش کیبورد برای تست» را بزنید.

نکته: Android اجازه نمی‌دهد یک برنامه بدون رضایت کاربر خودش را به‌عنوان کیبورد پیش‌فرض فعال کند؛ بنابراین فعال‌سازی اولیه از تنظیمات سیستم لازم است.


نسخه 16: مبنای ظاهری این پروژه همان تصویر مرجع ارسالی کاربر است؛ چیدمان اصلی بدون افزودن کلید یا پنجره جدید حفظ شده است.


نسخه 17.0: پنجره کیبورد از حالت تمام‌صفحه خارج شده و به‌صورت پنجره معمولی کیبورد با ارتفاع حدود 34٪ ارتفاع صفحه باز می‌شود. حالت Fullscreen/Extract غیرفعال و ADJUST_RESIZE فعال شده است.


نسخه 18: خطای build مربوط به getInputView() در FastInputMethodService اصلاح شد. ارتفاع کیبورد همچنان حدود 34 درصد ارتفاع صفحه است.

نسخه 19.0: هنگام لمس هر کلید، یک نور بسیار ملایم و یکنواخت تمام سطح همان کلید را روشن می‌کند. با برداشتن انگشت نور فوراً حذف می‌شود؛ چیدمان و ظاهر اصلی تغییر نکرده است.
