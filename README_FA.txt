Fast Keyboard — Reset 13

این پروژه مبنای فنی نسخه Reset 13 است.
صفحه اصلی کیبورد فقط شامل چیدمان اصلی است؛ Transparency، Copy History و Make Emoji از طریق گزینه‌های کشویی در دسترس هستند.
دکمه‌های فرمان ماشین و خود برنامه در Widget/Quick Settings در نظر گرفته شده‌اند.

نکته: کنترل واقعی فرمان یک بازی به API و ورودی‌های همان بازی وابسته است؛ این پروژه فقط زیرساخت کنترل شناور را فراهم می‌کند.

ساخت GitHub Actions: workflow داخل .github/workflows/android.yml است و Gradle 8.7 را در runner نصب/استفاده می‌کند؛ gradle wrapper لازم نیست.

نسخه 14.0 — پیاده‌سازی ظاهر اصلی مطابق تصویر مرجع ریست 13. صفحه اصلی عمداً بدون دکمه‌های اضافی نگه داشته شده است؛ Transparency، Copy History و Make Emoji فقط از کشوی Settings در دسترس‌اند و کنترل‌های فرمان ماشین/Widget خارج از صفحه اصلی هستند.
